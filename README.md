# HTB-cybersecurity-labs
Overview

This repository documents hands-on cybersecurity labs completed through Hack The Box (HTB). These exercises focus on developing practical skills in network connectivity, security monitoring, log analysis, and security operations.

Lab Projects
1. Pwnbox – Network Connectivity

    Launching and configuring the HTB Pwnbox environment.
    Establishing connectivity to target machines.
    Performing network connectivity tests using Ping.

2. Elasticsearch – Security Monitoring & Log Analysis

    Exploring Elasticsearch for security monitoring.
    Reviewing and analyzing logs.
    Identifying and documenting security events and observations.

Tools and Technologies

    -Hack The Box (HTB)
    -Pwnbox
    -Linux
    -Elasticsearch
    -Network diagnostic tools

Learning Objectives

   -Develop hands-on cybersecurity skills.
   -Understand network connectivity and troubleshooting.
   -Gain exposure to security monitoring technologies.
   -Build practical log analysis and security investigation experience.
